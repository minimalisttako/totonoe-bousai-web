# ととのえ防災

防災とお片付けを家庭に合わせて進めるPWA。公開候補 v86。

最新版: https://minimalisttako.github.io/totonoe-bousai-web/

## 初回リリースの実装範囲

安全点検・家庭の防災診断・避難計画・片付けとBefore/After写真・備蓄と点検・家族とペット・掃除の繰り返し・災害時モード・気象庁の天気と警報帯・例題15種類から毎回5問・学習動画・バックアップと復元。
キャラクターとまばたきは完成版で固定。

公開レビューのサーバー連携、イベント自動収集、河川情報の追加連携は今後の機能。現状のレビューはサンプル、イベントは外部検索。気象情報は取得した範囲を表示し、自治体・気象庁の公式情報を優先する。

## 更新時の一括検証

Python 3とNode.jsで、追加パッケージなしに実行:

```sh
python tests/release-check.py
```

- 重複ID、ラベル、画面移動先、インライン操作ハンドラーの参照先
- アプリとオフライン処理のJavaScript構文、キャッシュ版の一致
- 10種類の記録の復元、写真・家族メモ・地域設定の保持
- 保存失敗・未反映時の巻き戻し、読み取り不能時に書き込まないこと
- 破損した備蓄の保護、明示的な正常バックアップによる復元
- 備蓄単独復元で食数・トイレ回数の保持、不正な値の拒否、二段階確認

GitHub Actionsでmain更新・PR時にも同じコマンドを実行する。構造検証は画面の見た目やブラウザ操作の成功を保証しない。

## 正式公開までの残る実機確認

- Androidで起動・画面操作・保存・機内モード再起動
- 別端末への写真・家族メモ・地域設定を含むバックアップ復元
- 拡大文字と読み上げでの主要操作

iPhoneでの機内モード起動と備蓄・避難計画の表示は利用者確認済み。新しい版での再確認は実機結果として別に扱う。正式公開はこれらの確認完了後に判断する。

記録は端末・ブラウザ内。公開リポジトリには利用者の記録や秘密情報を含めない。
