# ととのえ防災

防災とお片付けを家庭に合わせて進めるPWA。公開Web版 v100。iPhoneの最終一括確認はv97で完了。v98以降は次期改善版。

最新版: https://minimalisttako.github.io/totonoe-bousai-web/

## 初回Web版の進捗

100%（主要9工程とv97のiPhone最終確認を完了、計10工程）。工程数での概算であり、作業時間や全構想の完成率ではない。具体的な根拠・未完了項目・一括確認内容は [RELEASE_STATUS.md](RELEASE_STATUS.md) に記録。2026年11月8日、利用者がv97の一括確認5点すべてOKと報告。iPhoneで確認済みの範囲で公開Web版を維持し、次期機能と未確認範囲は別に記録する。

## v96の食料・トイレ内容量

備蓄の新規登録・編集で、数量1単位あたりの食数・使用回数を任意入力できる。未確認なら空欄にでき、箱やセットを1食・1回とは推測しない。一覧に登録数量からの合計を表示する。同じ品目を別の期限で追加する場合、内容量を引き継ぎ、期限は空欄から確認して登録する。分類・単位を変更した場合は内容量をクリアし、以前の数字を誤用しない。既存の measureFactor を使い、保存・復元の形式は維持。入力・編集・複製・入力検証・保存失敗を自動テスト済み。

## v95の警報・注意報表示

同じ情報種別・コードの発表と解除を発表時刻で比較し、古い発表が解除後に残ることを防ぐ。情報種別ごとの「発表なし」を別種別へ波及させない。未知のコードは発表中の情報として残す。同時刻の矛盾、地域情報の欠落、古い情報、取得時刻の不整合、通信断を「なし」と表示しない。詳細画面もホームと同じ未確認判定を用いる。これらは合成データによる回帰テストであり、気象庁の全情報の網羅や災害時の運用保証ではない。

公式の確認先：https://www.jma.go.jp/bosai/warning/ （2026年11月8日確認）。アプリは警報の通知機能・避難指示の自動判定には対応しない。最新の気象庁・自治体情報を優先する。

## v94の設定復元

備蓄計算と停電・断水シミュレーターの初期読み込みで入力欄を保存値または初期値へそろえ、以前の未保存値が空欄へ混ざることを防ぐ。画面への読み込みと表示更新では保存しない。利用者の入力時には従来どおり保存する。復元した季節別点検・計算設定・シミュレーター設定と、ホームのメッセージも再描画する。空欄・旧形式・表示時の無書き込み・利用者操作時の保存をテスト済み。別端末への実際の移行確認は引き続き未確認。

## v93のホーム進捗連動

ホームの優先案内を安全・避難計画・片付け・備蓄の順で最大4件表示。上部ボタンと同じ判定を共有し、命を守る対策は片付け進捗に関係なく優先。最低限の備蓄は並行して確保する案内を維持。食料などの分類が未登録・数量0・期限切れなら備蓄案内を残す。診断を使わない場合も、共通ミッションと安全・避難・片付け・備蓄等の条件がそろえば定期掃除へ切り替える。診断ミッションやその他の安全点検が残る場合も案内する。共通ミッションの保存失敗時は完了状態を進めない。完了済みの季節点検は不要に再提示しない。保存形式とキャラクター素材は変更しない。

## v92の機能検索

「その他」上部から23機能を検索。掃除・自動解除・市区町村・買い足しなどの別名、全角英数字、複数語のAND検索に対応する。検索対象は機能の名前と説明で、利用者の記録は検索しない。通信・検索語の保存や送信は行わない。補充・備蓄計算・全データバックアップは該当欄を展開して直接案内。備蓄計算への移動で折りたたみが閉じたままになる不具合も修正。検索結果ゼロ・空欄・画面参照先・直接移動を自動テストする。

## v91の季節別点検

確認済み・対象外の最終確認から1年以上たった項目を再点検として区別し、未確認の項目とともに上部へ表示する。元の記録は自動削除しない。「今回も確認した」で日付を更新する。確認日が不明・不正・未来の場合も再点検に含める。1年はアプリ上の見直し目安と明記し、環境の変化時はそれ以前でも見直す。ホームには選択した季節の件数を表示。未選択なら端末の月に合わせた入口を使い、地域や気候に合わせて利用者が変更できる。バックアップ形式は維持。日付の境目、うるう年、再確認、保存失敗を自動テストする。

## v90の訓練・実践記録

「その他」から独立した訓練・実践記録を開ける。避難計画内の旧フォームは同じ記録画面への入口に変更。既存の `toto-evacuation-drills-v1` を引き継ぎ、避難・連絡・計画見直し・トイレ試用・備蓄食料試食・照明電源の動作確認・用品の使い方・家族の話し合いを記録できる。種類で絞り込み、実施日の新しい順に最大200件を表示する。未来日・存在しない日付を拒否し、保存失敗時は入力を残す。200件で新規保存を止め、従来のように古い記録を切り捨てない。読み取れない記録は上書きせず、バックアップ・復元にも対応。オフライン用HTMLに収録。

## v89の備蓄補充

実際に補充した数量を入力し、確認後にその分だけ在庫へ加算する。目標数へ一律に変更しない（3袋＋2袋＝5袋、目標10袋なら不足5袋）。期限・保管場所が違う場合は別に追加する導線を提供。期限切れ品への加算は拒否。数量の整数・上限と保存失敗を検証。最新の不足分を買い物用の補充メモとして表示・コピーできる。メモには品名・数量を含め、保管場所は含めない。自動送信しない。既存の保存形式を維持し、キャラクター素材は変更しない。

## v88の追加機能

「その他」→「引越し防災サポート」。転居前・荷造り・入居直後・地域の更新の4段階12項目を保存する。安全確保を先に進め、公式ハザードマップ・片付け・備蓄・安全点検・地域設定・避難計画・バックアップへ移動できる。本文と保存状態はオフライン対応。天気・安全点検の記録を自動で完了にはしない。全データバックアップの対象に `toto-moving-v1` を追加し、不正な値の拒否・正常な復元・チェックの解除と再読込をテスト済み。旧バックアップは引き続き読み込み可能。v86のiPhone確認をv88の実機確認とは扱わない。

出典リンク確認：国土地理院・国土交通省 ハザードマップポータルサイト https://disaportal.gsi.go.jp/ （2026年11月7日）。
