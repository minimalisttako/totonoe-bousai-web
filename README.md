# ととのえ防災

防災とお片付けを家庭に合わせて進めるPWA。公開候補 v90。

最新版: https://minimalisttako.github.io/totonoe-bousai-web/

## v90の訓練・実践記録

「その他」から独立した訓練・実践記録を開ける。避難計画内の旧フォームは同じ記録画面への入口に変更。既存の `toto-evacuation-drills-v1` を引き継ぎ、避難・連絡・計画見直し・トイレ試用・備蓄食料試食・照明電源の動作確認・用品の使い方・家族の話し合いを記録できる。種類で絞り込み、実施日の新しい順に最大200件を表示する。未来日・存在しない日付を拒否し、保存失敗時は入力を残す。200件で新規保存を止め、従来のように古い記録を切り捨てない。読み取れない記録は上書きせず、バックアップ・復元にも対応。オフライン用HTMLに収録。

## v89の備蓄補充

実際に補充した数量を入力し、確認後にその分だけ在庫へ加算する。目標数へ一律に変更しない（3袋＋2袋＝5袋、目標10袋なら不足5袋）。期限・保管場所が違う場合は別に追加する導線を提供。期限切れ品への加算は拒否。数量の整数・上限と保存失敗を検証。最新の不足分を買い物用の補充メモとして表示・コピーできる。メモには品名・数量を含め、保管場所は含めない。自動送信しない。既存の保存形式を維持し、キャラクター素材は変更しない。

## v88の追加機能

「その他」→「引越し防災サポート」。転居前・荷造り・入居直後・地域の更新の4段階12項目を保存する。安全確保を先に進め、公式ハザードマップ・片付け・備蓄・安全点検・地域設定・避難計画・バックアップへ移動できる。本文と保存状態はオフライン対応。天気・安全点検の記録を自動で完了にはしない。全データバックアップの対象に `toto-moving-v1` を追加し、不正な値の拒否・正常な復元・チェックの解除と再読込をテスト済み。旧バックアップは引き続き読み込み可能。v86のiPhone確認をv88の実機確認とは扱わない。

出典リンク確認：国土地理院・国土交通省 ハザードマップポータルサイト https://disaportal.gsi.go.jp/ （2026年11月7日）。

## v87の追加機能

「学ぶ」から「ミニマリストのススメ」を開ける。目的・整理・整頓と収納・備えと掃除の4章。必要な備えを減らさず、少なさを競わず、過去の自分と空間・使いやすさを比較するオリジナルガイド。片付け記録・成長アルバム・備蓄・掃除へ直接移動できる。本文はオフライン用HTML内に収録。新しい保存キーは追加しない。

v87のコード検証：300個のID・210個の操作設定、画面移動先、構文、オフライン版一致、復元とデータ保護、掃除の解除と安全優先、例題出題のテスト通過。v86のiPhone実機確認をv87の実機合格として転記しない。

## 初回リリースの実装範囲

安全点検・家庭の防災診断・避難計画・片付けとBefore/After写真・備蓄と点検・家族とペット・掃除の繰り返し・災害時モード・気象庁の天気と警報帯・例題15種類から毎回5問・学習動画・バックアップと復元。
キャラクターとまばたきは完成版で固定。

公開レビューのサーバー連携、イベント自動収集、河川情報の追加連携は今後の機能。現状のレビューはサンプル、イベントは外部検索。気象情報は取得した範囲を表示し、自治体・気象庁の公式情報を優先する。

## 更新時の一括検証

Python 3とNode.jsで、追加パッケージなしに実行:

```sh
python tests/release-check.py
```

- 重複ID、ラベル、画面移動先、インライン操作ハンドラーの参照先
- アプリとオフライン処理のJavaScript構文、キャッシュ版の一致
- 10種類の記録の復元、写真・家族メモ・地域設定の保持
- 保存失敗・未反映時の巻き戻し、読み取り不能時に書き込まないこと
- 破損した備蓄の保護、明示的な正常バックアップによる復元
- 備蓄単独復元で食数・トイレ回数の保持、不正な値の拒否、二段階確認

GitHub Actionsでmain更新・PR時にも同じコマンドを実行する。構造検証は画面の見た目やブラウザ操作の成功を保証しない。
