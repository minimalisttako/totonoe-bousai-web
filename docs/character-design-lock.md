# ととのえ防災：キャラクターデザイン固定仕様

この仕様は新規イラスト、アプリ画面、SNS用画像、アプリアイコンに共通して適用する。デザイン変更にはユーザーの明示的な承認が必要。

## たこ（必須）
- 本体はピンク色。茶色系の輪郭。柔らかい水彩・紙の質感。
- **黒の無地キャップ**を着用すること。野球帽型のつばを持つ「キャップ」であること。
- キャップには**ロゴ、家マーク、文字、エンブレム、刺繍、白線その他の装飾を一切入れない**。帽子の形を示す縫い目・通常の陰影は許容するが、模様に見える線は不可。
- **口を描かない**。目は残す。まばたき版でも口を加えない。
- 既に承認された体型・配色を勝手に変更しない。

## トリケラさん
緑色。くちばし・角はクリーム色。赤い頬や黒キャップを追加しない。

## シマエナガさん
白を基調とし、他の2キャラクターと同じ柔らかな水彩・紙の質感で統一する。
